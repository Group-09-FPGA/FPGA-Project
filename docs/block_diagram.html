RV32IM Softcore Processor — Three-Stage Microarchitecture

Lab 5 Baseline Refactored: Stage 1 (IF+ID) $ o$ Stage 2 (EX with RV32M Multiplier/Divider) $ o$ Stage 3 (MEM+WB with Bus Master)

100% Repository-Verified RTL
STAGE 1: IF + ID 1 Clock Cycle
Program Counter (PC)
PC[31:0] register with Next-PC selection (PC+4, Branch target from EX, Jump target).
Instruction Memory (IMEM)
1 RAMB36E1 Block RAM (1024 x 32 = 4 KB), parameterized latency wrapper.
Instruction Decoder
Extracts opcode, rd, rs1, rs2, funct3, funct7. Generates ALU opcodes & control strobes.
Immediate Generator
Sign-extends 32-bit immediates for I, S, B, U, and J instruction formats.
Register File (RF)
32 x 32-bit dual-read asynchronous ports (rs1, rs2) and single synchronous write port (rd).
STAGE 2: EX (EXECUTION) 1–33 Clock Cycles
Forwarding Unit
Zero-stall operand forwarding from WB and MEM stages to ALU input operands A & B.
Combinational ALU
32-bit single-cycle operations: ADD, SUB, AND, OR, XOR, SLL, SRL, SRA, SLT, SLTU.
rv32m_unit (4x DSP48E1)
Multi-cycle hardware multiplier (3 cycles: MUL, MULH, MULHSU, MULHU) and non-restoring divider (33 cycles: DIV, DIVU, REM, REMU).
Branch Evaluation
Branch condition evaluation (BEQ, BNE, BLT, BGE, BLTU, BGEU) and branch target calculation.
Hazard Control Unit
Detects bus wait-state stalls and multi-cycle divide busy flags; flushes pipeline on branch taken (2-cycle penalty).
STAGE 3: MEM + WB 1 Clock Cycle (Bus Deterministic)
Data Memory (DMEM)
4 KB distributed LUTRAM / Block RAM, byte-write enables (`wstrb[3:0]`).
System Bus Master
Initiates synchronous transactions with `req_valid`, `req_addr`, `req_wdata`, and handles `rsp_ready` handshake.
Write-Back Multiplexer
Selects among ALU output, RV32M math result, DMEM load data, and MMIO peripheral read data.
Register Commit
Synchronous write to destination register `rd` when `RegWrite` is asserted (register x0 hardwired to 0).

Pure-Hardware LOB Accelerator — Internal Storage & Search Engine

Audited v6 Defensible Architecture: 2-Way Cuckoo Hash + 64 CAM Stash $ o$ 3-Level Bitmask Tree $ o$ 84 BRAM Congestion-Safe Layout

Phase 1 Specification v6
1. Order-ID Hash & Stash
4,096 Active Capacity
Maps 32-bit internal Order-IDs to 12-bit slot pointers in BRAM.
2-Way Cuckoo Hash Table
Two independent CRC/XOR hash functions indexing dual BRAM banks.
64-Entry CAM Stash
Distributed LUTRAM CAM storing spillover entries. Exact Poisson overflow probability < 10⁻⁶.
2. Order Slot Table
4K Order Descriptors
Dual-ported BRAM storing Order-ID, Price Level Index (16b), Shares (32b), and Side bit.
Free-List FIFO
Provides O(1) single-cycle free slot allocation on ADD, and slot recycling on CANCEL/DELETE.
DOA_REG = 1 Latency
All read paths strictly registered to guarantee 100 MHz timing closure on Artix-7 -1 speed grade.
3. Price Level RAM
16,384 Total Levels
8,192 Bid levels + 8,192 Ask levels, representing contiguous tick increments around base price.
16 BRAM36s (Right-Sized)
Replaces hazardous 64-BRAM monolithic array, eliminating severe chip-spanning multiplexer congestion.
Aggregated Shares
Maintains total volume and active order count at each price tick for fast BBO queries.
4. Occupancy Tree & BBO
Level 0: Top Registers
16-bit register indicating which of the 16 major price blocks have active orders.
Level 1: Mid Mask
256-bit distributed LUTRAM bitmask indexing 1,024-entry blocks.
Level 2: Fine Mask
1K x 32 BRAM fine mask. Evaluated via priority encoder in 1–2 clock cycles.

Cycle-Accurate Operation Schedules & State Transitions

ORDER ADD ('A', 'F') 6 CYCLES
  1. Pop free slot FIFO & compute hash
  2. Write Order-ID to Hash Table
  3. Write descriptor to Slot RAM
  4. Read Price Level RAM (1 cyc DOA_REG)
  5. Increment aggregate volume
  6. Set bit in 3-Level Bitmask Tree & update BBO
EXECUTE / FILL ('E', 'C') 8–10 CYCLES
  1. Hash lookup & CAM stash search
  2. Read slot descriptor (price, shares)
  3. Subtract executed share quantity
  4. Read Price Level aggregate shares
  5. Update level volume in RAM
  6. If shares reach 0: push to free-list & clear bit
ORDER CANCEL / DELETE ('X','D') 8–10 CYCLES
  1. Lookup Order-ID in Hash Table
  2. Read slot entry & verify price/side
  3. Decrement price level volume
  4. Invalidate hash entry & free slot
  5. If level becomes 0: clear bit in occupancy tree
  6. Update BBO shadow register if level was top
COMPOUND REPLACE ('U') 15 CYCLES
  1. Lookup old Order-ID & retrieve resting side
  2. Atomic delete: decrement old price level
  3. Free old slot or reuse slot pointer
  4. Allocate new slot with new Order-ID
  5. Insert at new price level with updated shares
  6. Update 3-level occupancy bitmask & BBO

Fast-Path Network Ingestion & ITCH 5.0 Feed Handler

SMSC LAN8720A RMII PHY $ o$ MAC RX $ o$ IPv4/UDP $ o$ MoldUDP64 Session $ o$ ITCH Parser $ o$ Dual-Clock CDC FIFO

50 MHz RMII Domain

1. RMII PHY & MAC Receiver

LAN8720A RMII Interface: 2-bit RXD[1:0] sampled on rising edge of 50 MHz reference clock. Digilent Nexys A7 feeds 50 MHz out of pin D5 using Artix-7 ODDR primitive with 45° phase shift.

Preamble & SFD Detection: Detects 7 preamble bytes (0x55) followed by Start-of-Frame Delimiter (0xD5). Aligns dibits into aligned 8-bit bytes.

Hardware CRC32 Engine: Computes standard IEEE 802.3 32-bit Frame Check Sequence (FCS) on the fly. Corrupted or truncated frames are discarded immediately.

2. Protocol Decapsulation & Filtering

Ethernet Filter: Checks EtherType field (0x0800 for IPv4). Non-IP and VLAN-tagged frames are filtered without CPU overhead.

IPv4 / UDP Parser: Validates IP version 4, header checksum, protocol 0x11 (UDP), and destination UDP port (e.g., 10443).

Stock Locate Filter: Compares the 16-bit Stock Locate ID against MMIO configuration register `REG_TARGET_LOCATE`. Discards all non-target market messages.

3. MoldUDP64 & ITCH Messages

MoldUDP64 Header: 10-byte session header (Session ID, Sequence Number, Message Count). Detects packet drops and sequences stream.

Trading-Critical ITCH Messages:

  • 'A' Add Order (No MPID)
  • 'F' Add Order (With MPID)
  • 'E' Order Executed
  • 'C' Order Executed with Price
  • 'X' Order Cancel
  • 'D' Order Delete
  • 'U' Order Replace (Compound)

Clock Domain Crossing (CDC) Architecture (50 MHz $ o$ 100 MHz)

Because network packet arrival is asynchronous to the CPU and LOB core clock, canonical events must traverse from clk_eth_ref (50 MHz) into clk_core (100 MHz) without metastability or multi-bit skew.

Dual-Clock Asynchronous FIFO
128-bit wide, 64-entry deep FIFO with Gray-coded read/write pointers and 2-stage synchronizers on domain boundaries.
Reset Deassertion Hygiene
Independent 2-stage reset synchronizers ensure asynchronous assertion and synchronous deassertion within each clock domain.
Dual-Port BRAM Crossing
Native BRAM dual-port architecture isolates VGA raster scan clock (25.175 MHz) from LOB core updates (100 MHz).
